# ZG ZoneEconomy — 2026-10-17

## English — SERVER ONLY

Beta marketplace update with persistent listings and /oferta broadcasts. Offer cycles are per player and pause while offline; broadcasts do not automatically charge or exchange items. Back up the complete world and configuration before upgrading. To downgrade to 1.3.3, restore the matching pre-upgrade world backup as well: beta listings are not readable by 1.3.3.

Minecraft 1.20.1 / Forge 47.x / Java 17. ZG ZoneCore: required (server). ZG ZoneCrates: required (both). ZG ZoneEssentials: optional (server). ZG ZoneLag: optional (server). Stop the server/client before replacing JARs, keep only one version per side, and back up the world/configuration.

 Public protected distribution; private sources, obfuscation mappings and production account/configuration files are not included. Java obfuscation is not an absolute anti-decompilation guarantee. Original release checks and isolated protected-server startup are documented separately; graphical client, real multiplayer and full-modpack behavior are not certified by this upload.

## Español — SOLO SERVIDOR

Beta del mercado con anuncios persistentes y mensajes de /oferta. Los ciclos son individuales y se pausan al desconectarse; los mensajes no cobran ni intercambian objetos automáticamente. Respalda el mundo completo y la configuración antes de actualizar. Para volver a 1.3.3, restaura también el mundo previo: esa versión no lee las ventas guardadas por la beta.

Detén ambos lados antes de sustituir los JAR, deja una versión por lado y respalda mundo/configuración. Distribución pública protegida sin fuentes, mapas de ofuscación ni datos privados de producción. Las pruebas locales no certifican cliente gráfico, multijugador real ni modpack completo.
